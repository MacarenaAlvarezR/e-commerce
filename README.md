# DreSs - E-commerce de Moda 👗

## Descripción

Proyecto de una tienda online estática desarrollada con HTML5 y CSS3. La aplicación presenta un catálogo de productos organizado mediante CSS Grid y adaptado a diferentes dispositivos mediante técnicas de diseño responsive.

## Funcionalidades

- Catálogo visual de productos.
- Diseño responsive.
- Organización mediante CSS Grid.
- Categorías de productos.
- Tarjetas con imagen, nombre y precio.
- Interfaz limpia y adaptable.

## Tecnologías utilizadas

- HTML5
- CSS3
- CSS Grid
- Media Queries

## Conceptos aplicados

- Maquetación web.
- Diseño responsive.
- Organización de contenido mediante Grid Layout.
- Adaptación de interfaces para dispositivos móviles.
- Estructuración semántica de páginas web.
